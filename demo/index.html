How to read this

The candidate pool is every held-out test clip, with no filtering by ground-truth label, so clips that disagree with the sentence can and do rank highly. Each clip is a two-second window; the plots and the trajectory add three seconds of context on either side, drawn in grey, with the window itself in colour. Signals are shown at 10 Hz, selected from the 50 Hz source, and a channel the recording lacks is left as a gap rather than filled with zero. The bird's-eye trajectory turns the heading at the start of the context to point up; the vehicle outline is schematic, not a measured dimension. Only the six ontology labels are ground truth, and a category recorded as unknown stays unknown: it is never counted as agreement.

A sentence drawn from the fixed evaluation set carries declared states, so the table can compare them against each clip. A sentence you write yourself declares nothing, and the table then reports the clip's labels without a verdict.

Motion-to-Text ranks the clip's stored motion embedding against the stored sentence embeddings of the 5,670 descriptions that name one state in every category, the candidate pool of the paper's Motion-to-Text evaluation. The six states attached to the top description are the predicted motion classes; a green chip agrees with the clip's label, a red chip does not, and a dashed chip names a category the clip has no valid label for. No encoder runs in this direction, so it works before the 669 MB download.
